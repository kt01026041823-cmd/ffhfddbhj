# 미니창업 — 초대장 + 키오스크

설치 없이 브라우저로 여는 웹페이지 3개입니다.

| 파일 | 용도 |
| --- | --- |
| `index.html` | 시작 화면 (초대장/키오스크로 이동) |
| `invitation.html` | **초대장** — 손님 휴대폰용. 행사 안내 + 사전 주문 → 주문코드 발급 |
| `kiosk.html` | **키오스크** — 부스 태블릿/노트북용. 지금 주문 · 사전 주문(예약) · 예약 찾기 · 관리자 |
| `config.js` | **가게 이름, 날짜, 장소, 메뉴, 가격, 픽업 시간, 관리자 비밀번호** — 여기만 고치면 됩니다 |

## 흐름

1. **초대장**을 카톡 등으로 돌립니다. 손님이 메뉴·픽업 시간·이름·전화 뒷자리를 고르면
   `A2D1-1030-1234-김민수` 같은 **주문코드**가 나옵니다 (레몬에이드 2, 쿠키 1, 10:30 픽업).
2. 손님이 그 코드를 카톡으로 보내 주거나, 당일 키오스크의 **[사전 주문 찾기 → 코드 등록]**에 입력합니다.
   관리자 화면 **[사전 주문]** 탭에 카톡 내용을 통째로 붙여넣어도 코드만 골라서 한 번에 등록됩니다.
3. 당일엔 키오스크에서 **지금 주문**(번호 1, 2, 3…)과 **사전 주문**(P1, P2…)을 받습니다.
4. 오른쪽 위 ⚙️ → 비밀번호(기본 `0000`) → 관리자 화면
   - 주문 현황: `준비 완료` 누르면 손님 첫 화면에 번호가 뜹니다 → `전달 완료`
   - 사전 주문: 픽업 시간별로 묶어서, 시간대마다 준비할 수량 합계를 보여 줍니다
   - 매출: 메뉴별 판매량, 결제 방법별 금액, CSV(엑셀) 내보내기, 전체 초기화

## 알아 둘 점

- 주문 기록은 **키오스크를 연 그 기기의 브라우저**에 저장됩니다. 키오스크는 한 대에서 운영하고,
  끝나면 CSV로 내보내 두세요. (방문 기록 삭제/시크릿 창이면 지워집니다)
- 초대장은 서버가 필요 없어서 주문이 자동으로 전송되지는 않습니다 — 그래서 주문코드 방식을 씁니다.
- 손님에게 링크를 보내려면 인터넷 주소가 필요합니다. GitHub Pages(저장소 Settings → Pages)나
  Netlify Drop(폴더를 끌어다 놓기)에 올리면 무료로 주소가 생깁니다.
- `config.js`의 메뉴 `code`는 영문 대문자 한 글자로, 서로 겹치지 않게 해 주세요.
