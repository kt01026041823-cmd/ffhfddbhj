# 미니창업 키오스크 + 초대장

| 폴더 | 용도 |
| --- | --- |
| `kiosk/index.html` | 키오스크 — 지금 주문 · 예약 주문 · 예약 확인 · 관리자 |
| `kiosk/config.js` | 가게 이름, 메뉴, 가격, 픽업 시간, 관리자 비밀번호 |
| `kiosk/guide.html` | **운영 가이드** — 준비부터 당일 운영, 마감까지 |
| `invitation/index.html` | 초대장 (단독 파일, 맨 위 `INVITE` 설정만 고치면 됨) |

자세한 사용법은 `kiosk/guide.html`을 브라우저로 열어 보세요.
