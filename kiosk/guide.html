운영 가이드

초대장과 키오스크를 준비하고, 행사 당일 주문을 받고, 마감하는 방법까지 순서대로 정리했습니다.

구성

폴더누가, 어디서하는 일
invitation/손님 · 휴대폰행사 안내, 메뉴 소개, 사전 주문 → 주문코드 발급
kiosk/부스 · 태블릿/노트북지금 주문, 예약 주문, 예약 확인, 관리자(주문 처리·매출)
초대장에서 사전 주문→주문코드 발급→키오스크에 코드 등록→픽업 시간에 전달

행사 전 준비

  1. 키오스크 설정 바꾸기 kiosk/config.js를 메모장이나 VS Code로 열어 가게 이름, 메뉴, 가격, 픽업 시간, 계좌, 관리자 비밀번호를 바꿉니다. 
    { code: "A", name: "수제 레몬에이드", price: 2500, category: "음료", icon: "🍋", desc: "설명" }
    • code는 영문 대문자 한 글자이며 메뉴끼리 겹치면 안 됩니다.
    • category가 같은 메뉴끼리 왼쪽 분류에 묶입니다.
    • 재료가 떨어지면 soldOut: true를 추가하면 품절로 표시됩니다.
  2. 메뉴 사진 넣기 (선택) kiosk/images/ 폴더를 만들고 사진을 넣은 뒤 메뉴에 image: "images/lemonade.jpg"를 추가합니다. 가로:세로 4:3 사진이 가장 보기 좋습니다. 사진이 없으면 아이콘이 표시됩니다.
  3. 초대장 설정 바꾸기 invitation/index.html 맨 위의 INVITE 부분에서 날짜, 장소, 인사말, 메뉴를 바꿉니다.
    초대장 메뉴의 code와 가격은 키오스크 config.js와 반드시 똑같이 맞춰야 주문코드가 올바르게 읽힙니다.
  4. 인터넷에 올리기 손님이 초대장을 열려면 인터넷 주소가 필요합니다. 둘 중 편한 방법을 쓰세요.
    • Netlify Drop — app.netlify.com/drop 에 invitation 폴더를 끌어다 놓으면 바로 주소가 생깁니다.
    • GitHub Pages — 저장소 Settings → Pages에서 켜면 …github.io/저장소이름/invitation/ 주소가 생깁니다.
    키오스크는 인터넷에 올리지 않아도 됩니다. 부스 기기에서 kiosk/index.html을 바로 열어도 동작합니다.
  5. 리허설 팀원끼리 손님 역할을 나눠 지금 주문 3건, 예약 주문 2건, 초대장 코드 등록 1건을 해 보고, 관리자 화면에서 끝까지 처리해 봅니다. 끝나면 매출 → 모든 주문 삭제로 비웁니다.

초대장 보내기

초대장 주소를 카카오톡 등으로 보냅니다. 손님이 사전 주문을 하면 A2D1-1030-1234-홍길동 같은 주문코드가 나옵니다.

부분뜻
A2D1메뉴 A 2개, 메뉴 D 1개
103010:30 픽업
1234휴대폰 번호 뒷자리
홍길동이름

손님에게 “주문코드를 카톡으로 보내 주세요”라고 안내해 두면, 당일 전에 미리 한꺼번에 등록할 수 있어 편합니다.

당일 운영

키오스크 켜기

  1. 부스 기기 한 대에서 kiosk/index.html을 엽니다.주문 기록은 그 기기의 브라우저에만 저장되므로, 하루 종일 같은 기기·같은 브라우저를 사용하세요. 시크릿 창은 쓰지 마세요.
  2. 전체 화면으로 바꿉니다.노트북은 F11, 아이패드는 사파리 공유 → ‘홈 화면에 추가’ 후 실행하면 주소창 없이 보입니다.
  3. 화면 꺼짐을 끕니다.태블릿 설정에서 자동 잠금을 ‘안 함’으로 바꾸고 충전기를 연결해 두세요.

역할 나누기 (예시)

역할하는 일
안내키오스크 옆에서 처음 온 손님 도와주기
계산관리자 화면에서 ‘결제 확인’ 누르기, 현금·이체 확인
제조‘준비 중’ 목록 보고 만들기 → ‘준비 완료’ 누르기
전달번호 부르고 건네주기 → ‘전달 완료’ 누르기

관리자 화면은 키오스크 첫 화면 오른쪽 위 관리자 → 비밀번호로 들어갑니다. 계산 담당 휴대폰이나 다른 기기로 보고 싶다면, 같은 기기의 다른 탭에서 열어야 같은 주문이 보입니다.

주문 한 건의 흐름

손님이 주문→접수 (준비 중)→준비 완료→전달 완료
  • 준비 완료를 누르면 키오스크 첫 화면 아래 ‘준비 완료’ 칸에 번호가 표시됩니다.
  • 결제는 상태와 별개입니다. 돈을 받으면 언제든 결제 확인을 누르세요.
  • 잘못 누른 주문은 주문 취소, 실수로 끝낸 주문은 되돌리기로 복구합니다.
  • 손님이 2분 동안 아무것도 누르지 않으면 키오스크가 자동으로 첫 화면으로 돌아갑니다.

예약 주문 처리

예약이 들어오는 세 가지 경로

경로방법
키오스크에서 예약손님이 ‘예약 주문’으로 직접 주문 → 자동 등록 (P1, P2…)
초대장 코드를 카톡으로 받음관리자 → 예약 주문 탭 → 받은 카톡 내용을 통째로 붙여넣고 ‘등록’. 여러 건도 한 번에 됩니다.
손님이 당일 코드를 가져옴키오스크 첫 화면 → ‘예약 확인’ → 주문코드 입력 → 등록

같은 코드는 두 번 등록되지 않으니 걱정하지 않아도 됩니다.

픽업 시간 관리

관리자 → 예약 주문 탭은 픽업 시간 순서로 묶여 있고, 시간대마다 준비할 메뉴 합계가 표시됩니다. 픽업 10분 전에 미리 만들어 두고 ‘준비 완료’를 누르면, 해당 주문은 ‘주문 현황’의 전달 대기 목록으로 옮겨집니다.

손님이 오면 이름이나 휴대폰 뒷자리로 확인하세요. 손님이 키오스크 ‘예약 확인’에서 뒷자리 4자리를 눌러 직접 보여 줄 수도 있습니다.

마감

  1. 관리자 → 매출 탭에서 총 주문 금액, 결제 완료 금액, 미결제 금액, 메뉴별 판매량을 확인합니다.
  2. CSV(엑셀) 내보내기를 눌러 파일을 저장합니다. 엑셀이나 구글 시트에서 열립니다.
  3. 파일이 저장된 것을 확인한 다음에만 모든 주문 삭제를 누르세요. 삭제하면 되돌릴 수 없습니다.

체크리스트

행사 전날

  • config.js 메뉴·가격·비밀번호 수정
  • 초대장 메뉴 code·가격이 키오스크와 같은지 확인
  • 초대장 주소로 사전 주문 1건 테스트 → 키오스크에 등록되는지 확인
  • 리허설 후 모든 주문 삭제
  • 카톡으로 받은 사전 주문코드 미리 등록

행사 당일

  • 키오스크 기기 충전기 연결, 자동 잠금 끄기
  • 전체 화면 켜기
  • 거스름돈, 이체 확인할 휴대폰 준비
  • 마감 후 CSV 내보내기

자주 묻는 질문

초대장에서 주문하면 키오스크에 자동으로 들어오나요?
아니요. 서버 없이 동작하도록 만들어서 주문코드를 한 번 등록해야 합니다. 카톡으로 받은 내용을 붙여넣으면 한 번에 등록됩니다.
주문 기록이 사라졌어요.
다른 브라우저나 시크릿 창으로 열었거나, 방문 기록을 지운 경우입니다. 원래 쓰던 기기·브라우저로 다시 열어 보세요. 중간중간 CSV로 내보내 두면 안전합니다.
키오스크 두 대를 쓸 수 있나요?
각 기기에 따로 저장되기 때문에 번호가 겹칩니다. 한 대만 사용하는 것을 권장합니다.
주문코드가 형식이 맞지 않는다고 나와요.
초대장과 키오스크의 메뉴 code가 다른 경우입니다. 두 설정의 code를 똑같이 맞춰 주세요. 코드 사이의 -가 빠지지 않았는지도 확인하세요.
비밀번호를 잊어버렸어요.
kiosk/config.js의 adminPin 값을 확인하세요.
