운영 가이드 한눈에 보기 행사 전 준비 인터넷에 올리기 키오스크 화면 흐름 당일 운영 사전 주문 처리 마감 체크리스트 자주 묻는 질문

운영 가이드

초대장 사이트와 키오스크 앱을 준비하고, 당일 주문을 받고, 마감하는 방법을 순서대로 정리했습니다.

한눈에 보기

파일무엇누가, 어디서
shop/index.html초대장 — 가게와 메뉴를 소개하는 사이트손님 · 휴대폰/PC
shop/kiosk/키오스크 앱 — 주문 받기부스 태블릿 · 손님 휴대폰
shop/config.js가게 이름, 메뉴, 가격, 날짜 등 모든 설정준비하는 사람
초대장 사이트→ ‘앱 열기’ →키오스크 앱 (손님 휴대폰)→주문코드 발급→부스 키오스크에 등록

키오스크 앱은 두 가지 모드로 동작합니다.

모드여는 방법주문하면
부스 모드부스 태블릿에서 kiosk/ 주소를 직접 열기주문이 그 기기에 저장되고 번호표(1, 2, 3… / 예약은 P1, P2…)가 나옴
손님 모드초대장의 ‘앱 열기’ 버튼 (kiosk/?guest)저장되지 않고 주문코드가 나옴 → 부스에서 보여 주거나 카톡으로 보냄

행사 전 준비

  1. config.js 고치기 shop/config.js를 메모장이나 VS Code로 열어 가게 이름, 소개 문구, 날짜, 장소, 메뉴, 가격, 픽업 시간, 계좌, 관리자 비밀번호를 바꿉니다. 초대장과 키오스크에 함께 반영됩니다. 
    { code: "A", name: "수제 레몬에이드", price: 2500, category: "음료", icon: "🍋", best: true,
  desc: "키오스크에 보이는 짧은 설명",
  story: "초대장에 보이는 긴 소개" }
    • code — 영문 대문자 한 글자, 메뉴끼리 겹치면 안 됩니다. 행사 중간에 바꾸지 마세요.
    • best: true — ‘추천’ 표시 / soldOut: true — 품절 표시
    • color — 대표 색. 바꾸면 초대장과 키오스크 색이 함께 바뀝니다.
  2. 메뉴 사진 넣기 (선택) shop/images/ 폴더를 만들어 사진을 넣고, 메뉴에 image: "images/lemonade.jpg"를 추가합니다. 정사각형에 가까운 사진이 가장 잘 어울립니다. 사진이 없으면 아이콘이 나옵니다.
  3. 비밀번호 바꾸기 — adminPin을 팀원만 아는 숫자 4자리로 바꿉니다.
  4. 리허설 — 손님 역할을 나눠 매장·포장·예약 주문과 휴대폰 주문코드 등록을 한 번씩 해 보고, 관리자 화면에서 끝까지 처리해 봅니다. 끝나면 매출 → 모든 주문 삭제로 비웁니다.

인터넷에 올리기

손님이 초대장을 열려면 인터넷 주소가 필요합니다. shop 폴더 전체를 올리세요.

  • Netlify Drop — app.netlify.com/drop 에 shop 폴더를 끌어다 놓으면 바로 주소가 생깁니다. 수정한 뒤에는 다시 끌어다 놓으면 됩니다.
  • GitHub Pages — 저장소 Settings → Pages에서 켜면 …github.io/저장소이름/shop/ 주소가 생깁니다.

주소가 생기면 초대장 주소를 카카오톡 등으로 보냅니다. 부스 태블릿은 같은 주소 뒤에 kiosk/를 붙여서 엽니다.

예) 초대장 https://dalkom.netlify.app/ → 부스 키오스크 https://dalkom.netlify.app/kiosk/

키오스크 화면 흐름

대기 화면→주문 방법 (매장 · 포장 · 예약)→메뉴 선택→주문 확인→결제 수단→번호표
  • 대기 화면 — 메뉴가 하나씩 넘어가며 보이고, 아래에 ‘준비 완료’ 번호가 표시됩니다. 아무 곳이나 터치하면 시작합니다.
  • 메뉴 — 메뉴를 누르면 수량 창이 뜨고, ‘담기’를 누르면 아래 주문 내역에 들어갑니다.
  • 예약 주문은 주문 확인 단계에서 픽업 시간, 이름, 휴대폰 뒷자리를 받습니다.
  • 결제 수단은 기록용입니다. 실제 결제는 카운터에서 받고 관리자 화면에서 ‘결제 확인’을 누릅니다.
  • 손님이 60초 동안 아무것도 누르지 않으면 “주문을 계속하시겠어요?” 창이 뜨고, 10초 뒤 대기 화면으로 돌아갑니다.

관리자 화면 여는 법

대기 화면의 오른쪽 위 모서리를 빠르게 5번 터치 → 비밀번호 입력. 손님 눈에는 보이지 않는 숨은 버튼입니다.

당일 운영

키오스크 켜기

  1. 부스 태블릿 한 대에서 kiosk/ 주소를 엽니다.주문은 그 기기의 브라우저에 저장되므로 하루 종일 같은 기기·같은 브라우저를 쓰세요. 시크릿 창은 쓰지 마세요.
  2. 세로로 세워 두세요.세로형 키오스크 비율로 만들어져 있습니다. 가로 화면에서는 가운데에 세로로 표시됩니다.
  3. 전체 화면 — 아이패드는 사파리 공유 → ‘홈 화면에 추가’ 후 실행, 노트북은 F11.
  4. 자동 잠금 끄기, 충전기 연결.

역할 나누기 (예시)

역할하는 일
안내키오스크 옆에서 처음 온 손님 도와주기, 휴대폰 주문코드 받아서 등록
계산돈 받고 관리자 화면에서 ‘결제 확인’
제조‘준비 중’ 목록 보고 만들기 → ‘준비 완료’
전달번호 부르고 건네기 → ‘전달 완료’

주문 한 건의 흐름

접수 (준비 중)→ 준비 완료 →대기 화면에 번호 표시→ 전달 완료 →끝
  • 결제는 상태와 별개입니다. 돈을 받으면 언제든 결제 확인을 누르세요.
  • 잘못 들어온 주문은 주문 취소, 실수로 끝낸 주문은 되돌리기.
  • 관리자 화면은 키오스크 위에 겹쳐 열립니다. 손님이 기다리면 ‘키오스크로 돌아가기’를 누르세요.

사전 주문 처리

주문코드 읽는 법

예) A2D1-1030-1234-홍길동뜻
A2D1메뉴 A 2개, 메뉴 D 1개
103010:30 픽업 (0000이면 예약이 아닌 현장 주문)
1234휴대폰 번호 뒷자리
홍길동이름

등록하는 방법

상황방법
행사 전에 카톡으로 코드를 받음관리자 → 주문 현황 또는 예약 주문 탭 위 입력칸에 카톡 내용을 통째로 붙여넣고 ‘등록’. 여러 건도 한 번에 됩니다.
손님이 당일 휴대폰 화면을 보여 줌키오스크 → 예약 확인 · 주문코드 등록 → 코드 입력
부스 키오스크에서 바로 예약자동 등록 (P1, P2…)

같은 코드는 두 번 등록되지 않습니다. 손님에게 “주문코드를 카톡으로 보내 주세요”라고 안내해 두면 미리 등록할 수 있어 편합니다.

픽업 시간 관리

관리자 → 예약 주문 탭은 픽업 시간 순서로 묶여 있고, 시간대마다 준비할 메뉴 합계가 나옵니다. 픽업 10분 전에 만들어 두고 ‘준비 완료’를 누르세요. 손님은 키오스크 ‘예약 확인’에서 휴대폰 뒷자리로 자기 주문을 찾을 수 있습니다.

마감

  1. 관리자 → 매출 탭에서 총 주문 금액, 결제 완료, 미결제, 메뉴별 판매량을 확인합니다.
  2. CSV(엑셀) 내보내기로 파일을 저장합니다. 엑셀이나 구글 시트에서 열립니다.
  3. 파일 저장을 확인한 뒤에만 모든 주문 삭제를 누르세요. 되돌릴 수 없습니다.

체크리스트

행사 전

  • config.js 메뉴 · 가격 · 날짜 · 장소 · 비밀번호 수정
  • shop 폴더를 인터넷에 올리고 초대장 주소 확인
  • 휴대폰으로 ‘앱 열기’ → 예약 주문 → 코드를 부스 키오스크에 등록되는지 테스트
  • 초대장 주소 보내기
  • 리허설 후 모든 주문 삭제
  • 카톡으로 받은 주문코드 미리 등록

당일

  • 부스 태블릿에서 kiosk/ 열기 (손님 모드 주소 ?guest가 붙어 있지 않은지 확인)
  • 세로 거치, 전체 화면, 자동 잠금 끄기, 충전기 연결
  • 거스름돈, 이체 확인용 휴대폰
  • 마감 후 CSV 내보내기

자주 묻는 질문

손님이 휴대폰으로 주문하면 부스 키오스크에 자동으로 들어오나요?
아니요. 서버 없이 동작하도록 만들어서, 휴대폰 주문은 주문코드로 한 번 등록해야 합니다. 코드를 붙여넣기만 하면 됩니다.
부스 키오스크에서 주문했는데 번호표 대신 주문코드가 나와요.
주소 끝에 ?guest가 붙은 손님 모드로 열린 것입니다. 주소에서 ?guest를 지우고 다시 여세요.
주문 기록이 사라졌어요.
다른 브라우저나 시크릿 창으로 열었거나 방문 기록을 지운 경우입니다. 원래 쓰던 기기·브라우저로 여세요. 중간중간 CSV로 내보내 두면 안전합니다.
키오스크를 두 대 쓸 수 있나요?
기기마다 따로 저장되어 번호가 겹칩니다. 부스 키오스크는 한 대만 쓰는 것을 권장합니다.
관리자 화면이 안 열려요.
대기 화면(초록 화면)에서 오른쪽 위 모서리를 1.5초 안에 5번 눌러야 합니다. 비밀번호는 config.js의 adminPin입니다.
