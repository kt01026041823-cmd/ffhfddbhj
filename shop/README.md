# 달콤상점 — 초대장 + 키오스크 앱

| 파일 | 용도 |
| --- | --- |
| `index.html` | 초대장 — 가게와 메뉴를 소개하는 사이트. ‘앱 열기’로 키오스크 앱(손님 모드)으로 이동 |
| `kiosk/` | 키오스크 앱 — 대기 화면 → 매장/포장/예약 → 메뉴 → 결제 수단 → 번호표 |
| `config.js` | 가게 이름, 메뉴, 가격, 날짜, 장소, 비밀번호 — **여기만 고치면 됩니다** |
| `guide.html` | 운영 가이드 (준비 · 당일 운영 · 사전 주문 처리 · 마감) |

- 부스 태블릿: `kiosk/` 를 직접 열기 → 주문 저장, 번호표 발급
- 손님 휴대폰: 초대장의 ‘앱 열기’(`kiosk/?guest`) → 주문코드 발급 → 부스에서 등록
- 관리자: 키오스크 대기 화면 오른쪽 위 모서리를 5번 터치 (기본 비밀번호 `0000`)
