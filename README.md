# 네 개의 여름 (Four Summers)

> 같은 친구였지만 서로 다른 삶을 살았고, 결국 다시 만난다.

해원동 언덕에서 함께 자란 네 친구가 각각 **경찰 · 소방관 · 군인 · 의사**가 된 뒤의 이야기.
직업마다 완전히 다른 사건이 진행되고, **공간을 1인칭으로 둘러보며 편지와 기록을 직접 읽어**
15년 전 그해 여름에 무슨 일이 있었는지를 스스로 재구성하는 게임입니다.

빌드 도구도, 외부 라이브러리도, 이미지/음원 파일도 **하나도 없습니다.**
무대는 SVG로 그려지고, 소리는 그 자리에서 합성됩니다.

---

## 실행 방법

### 1) 브라우저에서 바로
```
index.html 을 브라우저로 열기
```
혼자 플레이와 로컬 협동이 설치 없이 바로 됩니다.

### 2) 데스크톱 앱 (Steam 배포용)
```bash
npm install          # electron + electron-builder
npm run desktop      # 앱으로 실행
npm run dist:win     # Windows 빌드  → dist/
npm run dist:mac     # macOS 빌드
npm run dist:linux   # Linux 빌드
```

### 3) 온라인 협동 서버
```bash
npm start            # 기본 3000번 포트 (의존성 없음)
```
`http://localhost:3000` 접속 → `친구들과 — 온라인` → 서버 주소 `ws://localhost:3000`, 방 코드는 아무 단어.

### 4) 스토리 검증
```bash
npm test             # = node tools/check.js
```

## 무엇을 하는 게임인가

### 1인칭으로 공간을 둘러본다
10곳의 공간이 있습니다. 마우스를 움직이면 시선이 따라 움직이고(시차), 빛이 그쪽을 비춥니다.
사물에 다가가 하나씩 살펴보고, 두 곳 이상을 본 뒤에야 그 방을 나갈 수 있습니다.

| 공간 | 무엇이 있는가 |
|---|---|
| 해원동 목재창고 (15년 전) | 열리지 않는 문, 서로 잡은 손목, 벽을 뜯는 소리 |
| 경찰서 미제 자료실 | 15년 전 8월 상자, 누락됐다던 별지, 종결 지시 공문 |
| 박정한의 반지하 방 | 신문 스크랩, 네 번째 예정지가 적힌 수첩, 엎어놓은 액자 |
| 소방서 장비보관실 | 일그러진 헬멧 「해원 3-7」, 출동기록부 원부, 이름표가 떼어진 사물함 |
| 언덕 위 마지막 가옥 | 벽에 걸린 사진, 부치지 않은 편지, 8월 14일에 동그라미 친 달력 |
| 대대 행정실 | 수정액으로 덮인 표창 대장 — 형광등에 비추면 획이 보인다 |
| 요양병원 3층 복도 | 창가에서 두 번째 침대의 문패, 15년째 빈 면회 기록판 |
| 요양병원 기록실 | 얇은 차트, 최초 이송 기록의 사고 장소 칸 |
| 침대맡 | 여러 번 폈다 접은 종이 한 장 |
| 철거 예정지 | 뜯긴 자국이 남은 벽, 넷이 가져온 종이 네 장 |

### 종이를 손에 쥐고 읽는다
**문서 12종** — 조사보고서, 출동기록부, 표창 대장, 의무기록, 그리고 **한상철이 부치지 못한 편지 3통.**
누렇게 바랜 종이로 펼쳐지고, 편지는 손글씨체로 나옵니다.

지워진 이름은 **먹칠**로 표시됩니다.
그해 여름을 충분히 알게 되면(기억 6개 이상) 수정액 아래 눌린 획이 비쳐 보입니다.
모은 문서는 **보관함(🗂️)** 에서 언제든 다시 읽을 수 있습니다.

### 소리가 절반이다
오디오 파일 없이 WebAudio로 전부 합성합니다.
장면마다 앰비언스가 다르고(자료실의 형광등 험과 초침, 병동의 심전도, 화재의 파열음),
**상처가 깊어질수록 소리가 낮고 답답해지며 심장 소리가 배경에 깔립니다.**

### 톤은 엔딩이 결정한다
플레이어의 상태가 그대로 화면과 소리에 밴습니다.
상처가 쌓이면 색이 빠지고 어두워지고, 유대가 높으면 다시 밝아집니다.
같은 장면도 어떤 사람이 되어 왔느냐에 따라 다른 색으로 보입니다.

## 세 가지 플레이 방식

| 모드 | 인원 | 서버 | 방식 |
|---|---|---|---|
| 혼자 플레이 | 1인 | 불필요 | 한 명의 삶을 끝까지. 나머지 셋은 이야기 속에서 만난다 |
| 친구들과 — 한 화면 | 2~4인 | 불필요 | 기기 하나를 돌려가며. **앞사람이 남긴 흔적이 뒷사람 이야기에 등장** |
| 친구들과 — 온라인 | 2~4인 | 필요 | 방 코드로 모여 동시 플레이. 선택이 실시간으로 넘어간다 |

네 사람의 이야기를 엮는 장치가 **세계 플래그**입니다.

| 플래그 | 만드는 사람 | 받는 사람에게 생기는 일 |
|---|---|---|
| `w_police_tip` | 👮 경찰 | 소방·군·의료 쪽에 대피/이송 준비 선택지가 열린다 |
| `w_fire_report` | 🚒 소방관 | 경찰의 방화 수사, 군의 무전 요청이 가능해진다 |
| `w_army_relief` | 🪖 군인 | 소방관이 진입로를 여는 선택지를 얻는다 |
| `w_doctor_hold` | 🩺 의사 | 현장 인력이 이송 순서를 맞출 수 있게 된다 |
| `w_name_hint` | 누구든 | 지워진 이름에 한 걸음 다가간다 |

선택지에 `친구의 흔적` 배지가 붙어 있으면, 다른 친구가 만들어준 선택지입니다.

## 이야기 구조

```
프롤로그 (공통)  ─ 불타는 창고 안을 직접 더듬는다. 벽을 뜯고 들어온 팔.
      │
      ├─ 👮 경찰   이도현 · 연쇄 방화 / 미제 자료실 / 5초의 추격
      ├─ 🚒 소방관 강민재 · 두 개의 방 / 폐기된 헬멧 / 명령 불이행 / 3분
      ├─ 🪖 군인   윤태오 · 혹서기 행군 / 지워진 표창 대장 / 사라진 병사
      └─ 🩺 의사   서하은 · 트리아지 / 얇은 차트 / "몇 명이었을까요"
      │
재회 챕터 (공통)  ─ 철거 직전의 언덕. 네 장의 종이를 겹쳐 놓는다.
      │
엔딩 ─ 숨겨진 진엔딩 / 해피 / 보통 / 새드
```

- 씬 **67개**, 선택지 **149개**, 문서 **12종**, 탐색 공간 **10곳**

### 네 개의 수치

| 수치 | 오르는 방식 |
|---|---|
| 🤝 유대 | 친구의 연락에 답하고, 남의 이야기를 끝까지 듣고, 함께 하기로 할 때 |
| 🔥 신념 | 규정과 원칙, 혹은 스스로 믿는 바를 지킬 때 |
| 🩹 상처 | 혼자 감당하고, 덮고, 지나칠 때 |
| 🧩 기억 | 그해 여름의 조각을 찾아낼 때 — **주로 방을 살펴보고 문서를 읽을 때** |

### 엔딩 조건

| 엔딩 | 조건 |
|---|---|
| 숨겨진 진엔딩 | 마지막에 **넷이 함께 찾아가는 선택** + 유대 30↑ + 기억 18↑ + 덮어버린 선택 없음 |
| 해피엔딩 | 유대 24↑ |
| 보통 엔딩 | 유대 12↑ |
| 새드 엔딩 | 그 밖 / 되돌릴 수 없는 선택을 안고 끝났을 때 |
| 멀티 합산 | **전원이 각자 진엔딩**이면 합산도 진엔딩 |

기준값은 추측이 아니라 `tools/check.js` 로 **실제 플레이 분포를 측정해서** 잡았습니다.
방을 지나치며 아무거나 누르면 유대 18 / 기억 13 근처(보통 엔딩),
공간을 꼼꼼히 살피고 친구를 챙기면 유대 32+ / 기억 19+(진엔딩)에 닿습니다.
**즉, 진엔딩은 문서를 읽지 않으면 열리지 않습니다.**

## Steam 배포 체크리스트

이미 되어 있는 것:

- `electron/main.js` — 전체화면(F11 / Alt+Enter), 창 크기·위치 기억, 단일 인스턴스,
  외부 링크 차단(심사 항목), 백그라운드 스로틀링 해제(앰비언스 끊김 방지)
- `electron/preload.js` — `contextIsolation: true`, `sandbox: true`. 게임에는 저장 경로만 노출
- `build/steam_appid.txt` — 빌드 시 실행 파일 옆에 복사됨 (현재 값 `480` = Spacewar 테스트 ID)
- `npm run dist:win` → `dist/FourSummers-1.0.0-win-x64.zip` 과 `dist/win-unpacked/`

출시 전에 직접 해야 하는 것:

1. `build/steam_appid.txt` 를 **본인 App ID** 로 교체
2. Steamworks → **실행 파일 경로**를 `four-summers.exe` 로 등록
3. **Steam Cloud (Auto-Cloud)** 저장 경로 등록 — 저장은 Electron의 userData에 들어갑니다
   - Windows: `%APPDATA%\four-summers`
   - macOS: `~/Library/Application Support/four-summers`
   - Linux: `~/.config/four-summers`
4. 스토어 페이지 에셋(카드/헤더/스크린샷)과 연령 등급 설정
5. 업적/오버레이가 필요하면 `greenworks` 같은 Steamworks 바인딩을 추가
   (현재는 SDK 없이도 실행되도록 되어 있습니다)

> 이 저장소에서 Windows/macOS 빌드는 만들어 보지 못했습니다(리눅스 컨테이너).
> **Linux 빌드는 실제로 만들어서 실행까지 확인**했고, 앱이 `steam_appid.txt` 를 읽어
> App ID 를 인식하는 것도 확인했습니다.

## 구조

```
index.html            화면 골격
css/style.css         테마 · 탐색 · 종이 · 톤 디렉터
js/engine.js          순수 상태머신 — 게임 규칙 전부
js/set.js             절차적 무대 화가 (SVG, 이미지 0개)
js/audio.js           절차적 사운드 (음원 0개)
js/story/index.js     씬·문서 저장소 + 엔딩 판정
js/story/docs.js      편지 · 기록 12종
js/story/rooms.js     1인칭 탐색 공간 10곳
js/story/common.js    프롤로그 · 재회 · 엔딩
js/story/{police,fire,army,doctor}.js   네 루트
js/save.js            저장 / 엔딩 도감
js/net.js             전송 계층 (오프라인 / WebSocket)
js/ui.js              DOM 렌더링 + 탐색·문서·톤
js/main.js            진행 컨트롤러
electron/             데스크톱 껍데기
server/server.js      방 서버 + 정적 서버 (의존성 없음)
tools/check.js        스토리 그래프 검증
```

설계에서 지킨 것:

1. **게임 규칙은 `engine.js` 와 `story/` 에만.** 서버는 규칙을 모르고 중계만 합니다.
2. **상태 전이는 순수 함수.** `Engine.apply(state, choiceId) → newState`.
   **방을 둘러보는 것도 똑같은 상태 전이로 구현**했습니다. 그래서 탐색까지
   저장·되감기·멀티 동기화가 공짜로 따라옵니다.
3. **에셋 0개.** 무대는 소품 목록으로 선언하면 SVG가 되고, 소리는 합성됩니다.

## 이야기를 더 쓰려면

대사 장면은 `js/story/*.js`, 탐색 공간은 `js/story/rooms.js`, 문서는 `js/story/docs.js` 에
데이터만 추가하면 됩니다. 코드는 건드릴 필요가 없습니다.

```js
Story.register([{
  id: 'room_new', type: 'look',
  chapter: '7화 · 제목', place: '장소', mood: 'night', amb: 'archive',
  intro: ['방에 들어설 때의 한두 줄.'],
  view: { pal: 'archive', seed: 5,
          back: [{ t: 'striplight', x: 800 }],
          mid:  [{ t: 'cabinet', x: 400 }],
          fore: [{ t: 'boxes', x: 1200 }] },
  hotspots: [
    { id: 'drawer', hx: 25, hy: 60, label: '서랍을 연다',
      text: ['살펴본 결과.'], doc: 'd_new', add: { memory: 1 } }
  ],
  choices: [
    { id: 'room_new:out', t: '나선다', req: { seenIn: 'room_new', min: 2 }, to: 'next_scene' }
  ]
}]);
```

쓸 수 있는 소품: `cabinet shelf desk chair window door striplight bulb lockers bed
ivstand hosereel helmet boxes clock pipes board rubble`

추가한 뒤 `npm test` 를 돌리면 끊긴 연결, 좌표 이탈, 없는 문서, 도달 불가능한 씬을
전부 잡아줍니다.
