# 네 개의 여름 (Four Summers)

> 같은 친구였지만 서로 다른 삶을 살았고, 결국 다시 만난다.

어린 시절 해원동 언덕에서 함께 자란 네 친구가 각각 **경찰 · 소방관 · 군인 · 의사**가 된
뒤의 이야기를 다루는 스토리형 선택지 게임입니다.
직업마다 완전히 다른 사건이 진행되고, 선택에 따라 사건의 결과와 인간관계가 달라지며,
**4종 엔딩(해피 · 보통 · 새드 · 숨겨진 진엔딩)** 으로 갈립니다.

빌드 도구도, 외부 라이브러리도 없습니다. 파일을 열면 바로 실행됩니다.

---

## 실행 방법

### 1) 혼자 플레이 / 로컬 협동 — 그냥 열기
```
index.html 을 브라우저로 열기
```
설치할 것이 없습니다. 저장(이어하기)과 엔딩 도감은 브라우저에 남습니다.

### 2) 온라인 협동 — 서버 실행
```bash
node server/server.js          # 기본 3000번 포트
node server/server.js 8080     # 포트 지정
```
그 다음 `http://localhost:3000` 으로 접속 →
`친구들과 — 온라인` → 서버 주소 `ws://localhost:3000`, 방 코드는 아무 단어(예: `HAEWON`).
같은 와이파이의 친구는 이 PC의 내부 IP(`ws://192.168.x.x:3000`)로 들어오면 됩니다.

> 서버도 **의존성이 없습니다**(`npm install` 불필요). WebSocket 핸드셰이크와 프레임을
> 순수 Node로 직접 처리하며, 정적 파일 서버도 겸합니다.

### 3) 스토리 검증
```bash
node tools/check.js      # = npm test
```
끊긴 선택지, 막힌 씬, 무한 루프, 4종 엔딩 도달 가능성, 씬 커버리지, 밸런스 분포를 검사합니다.

## 세 가지 플레이 방식

| 모드 | 인원 | 서버 | 방식 |
|---|---|---|---|
| 혼자 플레이 | 1인 | 불필요 | 한 명의 삶을 끝까지. 나머지 세 사람은 이야기 속에서 만난다 |
| 친구들과 — 한 화면 | 2~4인 | 불필요 | 기기 하나를 돌려가며 순서대로. **앞사람이 남긴 흔적이 뒷사람 이야기에 등장** |
| 친구들과 — 온라인 | 2~4인 | 필요 | 방 코드로 모여 동시 플레이. 선택이 실시간으로 서로에게 넘어간다 |

멀티에서 네 사람의 이야기를 엮는 장치가 **세계 플래그(world flag)** 입니다.

| 플래그 | 만드는 사람 | 받는 사람에게 생기는 일 |
|---|---|---|
| `w_police_tip` | 👮 경찰 | 소방·군·의료 쪽에 대피/이송 준비 선택지가 열린다 |
| `w_fire_report` | 🚒 소방관 | 경찰의 방화 수사, 군의 무전 요청이 가능해진다 |
| `w_army_relief` | 🪖 군인 | 소방관이 진입로를 여는 선택지를 얻는다 |
| `w_doctor_hold` | 🩺 의사 | 현장 인력이 이송 순서를 맞출 수 있게 된다 |
| `w_name_hint` | 누구든 | 15년 전 지워진 이름에 한 걸음 다가간다 |

선택지에 `친구의 흔적` 배지가 붙어 있으면, 그건 **다른 친구가 만들어준 선택지**입니다.

## 이야기 구조

```
프롤로그 (공통)  ─ 15년 전, 해원동 목재창고의 불과 이름 모를 구조자
      │
      ├─ 👮 경찰   이도현 · 재개발 지구 연쇄 방화 / 미제 자료실 / 5초의 추격
      ├─ 🚒 소방관 강민재 · 두 개의 방 / 낙하물 / 명령 불이행 / 폐기된 헬멧
      ├─ 🪖 군인   윤태오 · 혹서기 행군 / 은폐 압박 / 산불 지원 / 사라진 병사
      └─ 🩺 의사   서하은 · 트리아지 / 다수 사상자 / 의료 판단의 책임
      │
재회 챕터 (공통)  ─ 철거 직전의 언덕에서 넷이 다시 만난다
      │
엔딩 ─ 숨겨진 진엔딩 / 해피 / 보통 / 새드
```

- 씬 **57개**, 선택지 **146개**
- 각 루트에서 다른 세 친구가 실제로 등장하고(현장에서 마주치거나 서로를 병원에 데려온다),
  네 사람이 각자 찾아낸 조각이 하나의 이름으로 맞춰집니다.

### 4개의 수치

| 수치 | 오르는 방식 |
|---|---|
| 🤝 유대 | 친구의 연락에 답하고, 남의 이야기를 끝까지 듣고, 함께 하기로 할 때 |
| 🔥 신념 | 규정과 원칙, 혹은 스스로 믿는 바를 지킬 때 |
| 🩹 상처 | 혼자 감당하고, 덮고, 지나칠 때 |
| 🧩 기억 | 그해 여름의 조각을 찾아낼 때 (루트마다 다른 경로) |

### 엔딩 조건

| 엔딩 | 조건 |
|---|---|
| 숨겨진 진엔딩 | 마지막에 **넷이 함께 찾아가는 선택** + 유대 20↑ + 기억 8↑ + 덮어버린 선택 없음 |
| 해피엔딩 | 유대 16↑ |
| 보통 엔딩 | 유대 8↑ |
| 새드 엔딩 | 그 밖 / 되돌릴 수 없는 선택을 안고 끝났을 때 |
| 멀티 합산 | **전원이 각자 진엔딩**이면 합산도 진엔딩 |

기준값은 `tools/check.js` 로 실제 플레이 분포를 측정해서 잡았습니다
(아무거나 누르면 유대 12 근처 → 보통 엔딩, 친구를 챙기면 25 이상 → 진엔딩).

## 구조

```
index.html            화면 골격 (7개 화면)
css/style.css         장면 분위기(mood)에 따라 배경색이 변하는 테마
js/engine.js          순수 상태머신 — 게임 규칙 전부
js/story/index.js     씬 저장소 + 엔딩 판정
js/story/common.js    프롤로그 · 재회 챕터 · 4종 엔딩
js/story/police.js    👮 경찰 루트
js/story/fire.js      🚒 소방관 루트
js/story/army.js      🪖 군인 루트
js/story/doctor.js    🩺 의사 루트
js/save.js            저장 / 엔딩 도감 (localStorage)
js/net.js             전송 계층 (오프라인 더미 / WebSocket)
js/ui.js              DOM 렌더링
js/main.js            진행 컨트롤러 (혼자 / 핫시트 / 온라인)
server/server.js      방 서버 + 정적 파일 서버 (의존성 없음)
tools/check.js        스토리 그래프 검증
```

설계에서 지킨 것 두 가지:

1. **게임 규칙은 `engine.js` 와 `story/` 에만 있다.** 서버는 규칙을 모르고 중계만 하며,
   엔딩 판정도 클라이언트가 합니다. 규칙이 두 곳에 생기면 반드시 어긋나기 때문입니다.
2. **상태 전이는 순수 함수다.** `Engine.apply(state, choiceId) → newState`.
   그래서 네트워크로 보낼 것이 선택지 id 하나로 끝나고, 멀티에서 모든 화면이
   같은 결과에 도달합니다.

## 이야기를 더 쓰려면

`js/story/*.js` 에 씬 객체를 추가하면 됩니다. 코드는 건드릴 필요가 없습니다.

```js
Story.register([{
  id: 'police_13',
  chapter: '7화 · 제목', place: '장소', mood: 'night', at: 0.83,
  text: [
    '지문은 문자열로 씁니다.',
    ['도현', '대사는 [이름, 대사] 로 씁니다.']
  ],
  choices: [
    { id: 'police_13:a', t: '선택지 문구',
      add: { bond: 2, memory: 1 },     // 수치 변화
      set: { some_flag: true },        // 내 루트용 플래그
      world: 'w_police_tip',           // 친구들에게 넘길 흔적
      req: { stat: 'memory', min: 3 }, // 이 선택지가 보이는 조건
      to: 'police_14' }                // '#ending' / '#route' 도 가능
  ]
}]);
```

추가한 뒤 `node tools/check.js` 를 돌리면 연결이 끊긴 곳을 바로 잡아줍니다.

## 조작

- 화면 클릭 또는 `Space` — 다음 문장
- 숫자키 `1`~`9` — 선택지
- 📜 기록 · 👥 친구들 · 💾 저장 · ✕ 나가기
- `Esc` — 서랍 닫기
